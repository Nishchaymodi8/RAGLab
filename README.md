# RAGLab

A platform for evaluating, benchmarking, and diagnosing Retrieval-Augmented Generation (RAG) pipelines.

## Project Status

Initial setup and full-stack foundation.

## Planned Technology Stack

- Backend: Python, Django, Django REST Framework
- Frontend: React, JavaScript, Vite
- Database: PostgreSQL
- RAG evaluation: Local embeddings, retrieval metrics, and pgvector
